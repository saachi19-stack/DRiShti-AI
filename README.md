# 👁️ DRiShti-AI

### Explainable AI for Diabetic Retinopathy Screening in Rural India

DRiShti-AI is an AI-assisted diabetic retinopathy screening platform designed to support early screening and referral prioritization, particularly in rural and low-connectivity environments.

## 🚀 Key Features

- Retinal fundus image screening
- Automated image-quality assessment
- Diabetic retinopathy severity classification
- Explainable AI using Grad-CAM
- Risk and referral prioritization
- Rural and low-connectivity workflow
- Local screening history
- Automated screening report generation
- PDF report download

## 🔄 Workflow

Retinal Image  
↓  
Image Quality Assessment  
↓  
AI-Based DR Screening  
↓  
Severity Classification  
↓  
Explainable AI / Grad-CAM  
↓  
Risk Assessment  
↓  
Referral Prioritization  
↓  
Screening Report

## 🧠 DR Severity Classes

1. No Diabetic Retinopathy
2. Mild Diabetic Retinopathy
3. Moderate Diabetic Retinopathy
4. Severe Diabetic Retinopathy
5. Proliferative Diabetic Retinopathy

## 🛠️ Technology Stack

- Python
- Streamlit
- TensorFlow / Deep Learning
- OpenCV
- NumPy
- Pandas
- Scikit-learn
- Grad-CAM
- ReportLab

## 🌐 Rural Healthcare Focus

DRiShti-AI is designed around a low-connectivity screening workflow where screening records can be stored locally and synchronized when connectivity becomes available.

## ⚠️ Disclaimer

DRiShti-AI is an AI-assisted screening prototype and does not replace professional medical examination, clinical judgment, or diagnosis by a qualified healthcare professional.
